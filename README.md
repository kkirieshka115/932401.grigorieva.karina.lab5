## Описание

В данной работе реализовано интерактивное управление списком гипотез с использованием DOM-манипуляций и сохранением состояния в localStorage.

## Что реализовано

- **Поиск элементов:** использованы `getElementById`, `querySelector`, `querySelectorAll` для доступа к элементам страницы.
- **Манипуляции с DOM:** создание новых карточек гипотез через `createElement`, изменение текста через `textContent`, добавление и удаление классов через `classList`, динамическое добавление элементов в контейнер.
- **Переключение темы:** кнопка «Переключить тему» добавляет/удаляет класс `dark-theme` у `body`, меняя цветовую схему страницы.
- **Скрытие/показ блоков:** кнопка «Скрыть гипотезы» переключает класс `hidden` у контейнера гипотез, скрывая или показывая секцию.
- **Обработка ошибок:** перед каждым действием проверяется существование элемента; если элемент не найден — выводится сообщение в консоль.
- **Сохранение в localStorage:** список гипотез и выбранная тема сохраняются при изменениях и восстанавливаются при загрузке страницы.

## Функциональность

- Кнопка «Добавить гипотезу» создаёт новую карточку с запросом названия и формулировки через `prompt`.
- Кнопка «Изменить статус» на каждой карточке циклически меняет статус: не проверена → в процессе → подтверждается.
- Кнопка «Скрыть гипотезы» скрывает/показывает секцию с карточками.
- Кнопка «Переключить тему» меняет цветовую схему между светлой и тёмной.

## Как проверить работу

1. Откройте `index.html` в браузере или через GitHub Pages.
2. Нажмите «Добавить гипотезу» — введите название и формулировку.
3. Нажмите «Изменить статус» на любой карточке — статус изменится.
4. Нажмите «Скрыть гипотезы» — секция скроется, кнопка изменит текст на «Показать гипотезы».
5. Нажмите «Переключить тему» — страница перейдёт в тёмный режим.
6. Перезагрузите страницу — все изменения (гипотезы и тема) сохранятся.
